# 播放控制光学居中修复设计

## 问题

播放按钮使用 Unicode `▶`。字体字形左右留白不对称，并受文字基线影响，因此即使按钮盒模型几何居中，三角形仍显得向右、向下偏移。

## 方案

- 使用无文本的 CSS 三角形替换 Unicode 播放字符，暂停状态使用两根 CSS 竖条。
- 主按钮使用 `display: grid` 和 `place-items: center` 保证几何中心稳定。
- 播放三角形仅增加约 2px 的水平光学校正；上一首、主按钮、下一首继续以相同间距围绕中心排列。
- 保留原有 `aria-label`，视觉图形设为隐藏语义内容，不改变键盘和读屏交互。

## 验证

- 在桌面与 390px 移动视口截图检查按钮组中心线和图标光学中心。
- 验证播放/暂停点击后图标、可访问名称和播放状态同步。
- 运行 TypeScript/Vite 生产构建，并重新发布静态产物。
