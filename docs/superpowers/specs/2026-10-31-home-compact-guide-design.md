# 首页精简与互动指南设计

日期：2026-10-31。状态：设计待用户复核，尚未实施。

## 目标与取舍

首页改为「全屏个人首屏 → 四张互动入口卡 → 简洁页脚」。移除六个独立大板块在首页的展示，保留文章、作品、工具、留言、音乐、AI 电商与管理后台的独立功能。仅本地验收，未经再次授权不推送、不发布，不修改用户的 output/。

推荐原位展开四卡：浏览时保持紧凑，点击后再显示内容；不采用四张普通跳转卡（互动不足），也不将所有内容再平铺到首页（违背精简目标）。

参考站为 https://tblog.mmzhiku.xyz/ 。已通过公开 HTML 和 HomeDataLayer 脚本核对：四卡单选原位展开、同卡/空白收起、统计轮换、文章自动翻牌和横向拖动、分类与标签折叠、联系入口列表。浏览器页面可读取，但实际点击多次超时，未将源码核对冒充点击实测。只借鉴信息组织和行为，不复制其 JS、插画、文章、文案或个人标识。

## 首屏

- 保留全屏 GradientWaves、WENHAO ParticleText 的现有指针/触屏交互，以及循环 TextType。
- 删除巨大的「博客.」、顶部「文昊的个人空间 / 持续探索，认真创造」和「开始阅读 / 查看作品」按钮。
- 身份只显示「AI 工程师」，不再列三个职业。
- 重新收紧 WENHAO、身份、循环短句的间距；文字不另套卡片，首屏保留充足呼吸空间。
- 下探指引指向新四卡区域，不再指向删除的 featured 锚点。撤除首屏多余状态装饰。

## 右上设置与浮层

右上把搜索与主题两个常驻入口合成一个 48px 设置图标按钮。点击打开锚定下拉面板，依次为搜索、公告、主题；点击外部或 Esc 关闭，键盘可操作。

- 搜索：全屏暗化和模糊遮罩，上方居中的宽胶囊输入框；未输入时不堆满结果。输入后按现有全站搜索数据展示文章/工具/页面等结果；Enter 打开首个结果，Esc 关闭。Ctrl/Cmd+K 在无其他模态框时切换搜索。保留焦点圈、焦点限制和退出后焦点归还。
- 公告：独立居中模态框，标题/关闭、可滚动更新列表、底部「我知道了」。公告内容来自本地有类型的数据，只陈述本站真实改动，不抄参考站日期与内容。公告链接跳转后关闭。
- 主题：浅色、深色、跟随系统三个带可访问名称的图标选项。存储用户的模式偏好；系统模式监听系统变化，不把解析出的深浅色覆盖为手动偏好。兼容现有用户保存的 dark/light。实际 Theme 仍为 dark/light 传给现有视觉组件。
- 一次只打开一个浮层；设置、中心导航、搜索、公告互斥，不让背景继续获得焦点。
- 中央现有主导航不在本轮另做 1:1 复刻，但修复被移除首页锚点：文章/笔记进入现有文章索引，关于与联系打开联系指南，管理员入口与独立功能保留。

## 四卡区域

桌面两列两行，手机单列。统一圆角、薄边框、暖白/紫黑主题面，使用自己绘制的轻量 SVG/CSS 视觉；不增加重型 3D 依赖。展开卡在区域内占满两列，其他卡保持可发现、可切换；一次最多展开一张，点同一触发按钮、明确收起按钮或区域背景可收回。卡内链接、滑动与控件不触发父卡收起。不使用嵌套按钮或把整张含链接的卡做成按钮。

1. **站点数据**：原创层叠档案/数据图形，预览轮换真实内容指标；展开显示文章、分类、标签、工具数量。计数从同一份内容元数据派生。没有已接入的可信访客服务就不显示访客/访问量，不新建统计后端、不制造数字。
2. **博客文章**：从本站文章摘要和封面派生最新内容卡叠，自动轮播、悬停/键盘聚焦暂停、左右按钮与横向拖动切换；垂直触屏滚动不被截断。展开为最新文章列表和「全部文章」链接；只有元数据确实标记置顶时才显示置顶分组。条目跳到现有文章路由。
3. **内容索引**：原创分支目录图，实际分类/标签及计数；展开后分类和标签可折叠，点击进入现有文章索引并应用相应过滤。数据源不重复维护；空分类不伪造。
4. **订阅与联系**：原创节点轨道图，展开实际可用的本站联系与留言入口；只展示仓库中已验证的真实地址。未确认邮箱或尚无 RSS 服务不伪装可用，不复制参考站 QQ/B站/GitHub。AI 电商、作品等功能继续由主导航访问。

不复制参考站后续百叶窗、角色对话、历史时间线等额外板块。首页只保留首屏、四卡、页脚和已有小音乐按钮。

## 边界与组件

复用现有 ModalSurface、内容摘要、路由、鉴权和音乐浮层。新增独立设置菜单/公告组件、四卡控制器及四种卡片视图，避免把所有状态塞入 HomePage。搜索保持现有搜索索引逻辑；主题偏好与解析 Theme 分离。原首页组件可留在仓库，不因撤下展示而删除独立功能。

## 异常、性能与验收

- 空文章、无封面、无联系信息均有诚实空状态；图像失败提供不跳布局的替代图形。
- 轮播只在可见且页面活跃时运行，卸载清理计时器；低动效关闭轮播/拖动惯性和位移动画，静态内容仍可点击。
- 所有交互目标至少 44px，语义按钮和 aria-expanded/controls 正确；关闭/切换后不遗留隐藏焦点。手机不依赖 hover。
- 测试设置菜单互斥/关闭/焦点、搜索快捷键/Enter/空状态、三态主题持久化与系统事件、公告、四卡展开/收起、轮播暂停/清理、索引过滤及被撤下锚点的兼容性。
- 完整测试与构建通过；浏览器在 1440×1000、1024×900、390×844 深浅主题实测首屏与四卡，检查无遮挡、无横向溢出、音乐按钮安全间距、键盘和低动效。
- 本地交付后等待用户视觉确认，最后才谈 GitHub 和上线。
