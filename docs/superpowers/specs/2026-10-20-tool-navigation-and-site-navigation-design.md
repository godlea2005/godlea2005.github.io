# 工具导航与全站导航重构设计

日期：2026-10-20  
状态：用户已确认方向，待实现  
范围：新增独立工具导航页、收束全站导航、工具检索与分类、桌面端目标光标反馈；不重做首页 Hero，不改变 AI 电商、留言、音乐或后台的数据流程。

## 1. 背景与目标

站点现有“工具导航”链接到首页的 `#studio-map` 能力介绍区，不能承担收藏、查找和打开真实工具的任务。用户希望拥有一个类似参考博客中“工具导航”的独立页面，但明确要求保留原创性，不能一比一复刻对方的视觉、文案或素材。

完成后，访客应能从任意页面直接进入一个可搜索、可筛选、能说明用途的工具目录；工具页要像文昊本人正在使用的工作台，而不是通用网址导航站。

## 2. 设计依据与原创边界

借鉴的是信息组织原则：大标题建立入口感、分类降低浏览成本、卡片提供用途与域名、导航保持短而安静。不会复用参考站的标题、引语、青色竖线、灰色卡片比例、具体图标组合、图片、角色、文案或背景纹理。

本站独立视觉语言：

- 深色：石墨底、雾紫层次、草木绿作为少量操作色。
- 浅色：暖白纸张、石墨文字、低饱和蓝紫和草木绿。
- 分类以编号轨道、计数和筛选胶囊表达，不使用参考站的竖线标题结构。
- 卡片包含“适合什么场景”和“为什么收藏”，这是工具目录的个人判断层。

## 3. 信息架构

新增精确 hash 路由 `#tools`。它是独立页面，不复用首页 `#studio-map`；后者继续代表文昊的能力与工作方式。

一级导航调整为：

1. 主页
2. AI 电商
3. 工具导航
4. 文章（实验记录、作品归档）
5. 联系（留言、合作）
6. 更多（音乐、关于、站长后台）

搜索弹层将“工具导航”指向 `#tools`。`#tools` 作为子页时，首页内容不渲染，顶部导航和紧凑音乐入口保留。

## 4. 页面结构

### 4.1 工具页首屏

- 目录编号、页面标题“工具导航”和一句个人筛选标准。
- 页面右侧或标题下方展示已收录工具数量与更新时间提示。
- 搜索框在桌面端位于标题区，在移动端置于标题下方；输入时即时过滤工具名称、用途、标签和个人注记。
- 分类筛选采用可横向滚动的紧凑胶囊：全部、AI 创作、跨境电商、图像与素材、效率与开发、灵感与阅读。

### 4.2 分类与工具卡

每个分类由编号、中文分类名、简短说明和收录数量组成。工具卡呈三列网格，依次降为两列和单列。卡片包含：

- 可识别的小图形或首字母，不抓取或复制第三方品牌素材。
- 工具名、场景说明、域名、个人注记和外链箭头。
- 可选标签，例如“俄语市场”“提示词”“图片压缩”。
- 鼠标悬停时轻微上移、边界提亮、显示“打开工具”；键盘焦点有明显轮廓。

首批内容以真实工作流组织：AI 创作、跨境电商、图像与素材、效率与开发、灵感与阅读。每个外链在提交前须核对官方地址，并使用 `target="_blank" rel="noreferrer"`。

### 4.3 空态与异常

- 搜索无结果时显示输入词与“清除筛选”动作。
- 数据为空时显示安静的目录空态，不出现模拟加载结果。
- 外链不在页面内嵌，不记录访问者行为。

## 5. 交互与动效

桌面端加入 Target Cursor 风格的自制目标框光标效果：只绑定普通链接、按钮与标记为可吸附的工具卡。目标框会平滑吸附到元素边缘并显示简短标签。

不在输入框、文本域、下拉框、滑条、文件上传、可编辑内容、模态层、AI 电商表单、留言编辑或音乐进度条上隐藏原生鼠标。移动端和 `prefers-reduced-motion: reduce` 下完全关闭目标光标。

导航下拉沿用现有可访问性机制：外点关闭、Escape 关闭、焦点返回触发按钮；新增入口后在 1080px 左右提前切换到移动目录，避免 1024px 宽度发生品牌、菜单和搜索控件挤压。

## 6. 组件边界

- `ToolNavigationPage`：页面布局、搜索/筛选状态、分类渲染、空态。
- `tools.ts`：工具类别与工具条目的静态数据模型，不混入 `site.ts`。
- `TargetCursor`：独立的轻量前端反馈组件，处理 pointer、键盘降级、目标测量和清理。
- `FloatingHeader`：只处理全站导航、当前页状态和搜索目录，不持有工具页筛选状态。
- `tool-navigation.css`：工具页专属样式，避免继续向历史全局样式表追加规则。

## 7. 响应式与可访问性

- 1440px：工具卡三列，最大内容宽度约 1280px。
- 1024px：两列卡片，导航收起为目录面板。
- 640px 以下：单列卡片、可横向滚动的筛选胶囊、最小 44px 点击区域。
- 工具页底部留出至少 96px 安全距离，避免紧凑音乐入口覆盖最后一张卡。
- 筛选使用原生 button 和 `aria-pressed`；搜索有可见 label；外链提供可辨识的名称；所有运动尊重系统减少动态偏好。

## 8. 验证

- 为数据模型、`#tools` 路由、导航当前态、筛选/空态与外链安全属性补充针对性单元测试。
- 运行现有测试与生产构建。
- 用真实浏览器在 1440px、1024px、390px 下检查深浅主题、直达 `#tools`、分类筛选、搜索、移动目录、Escape、焦点、无横向溢出、最后一张卡不被音乐入口遮挡。
- 目标光标只在桌面指针设备上显示，键盘导航和表单输入仍保持原生可用。
