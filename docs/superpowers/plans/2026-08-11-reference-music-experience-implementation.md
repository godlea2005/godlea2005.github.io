# 高还原 WebGL 音乐体验实施计划

## 1. 依赖与数据模型

- 安装 `three` 与 `@types/three`。
- 新建 `src/music/types.ts`，定义曲目、循环模式、歌词和播放器状态。
- 新建 `src/music/tracks.ts`，集中管理两首本地曲目及原创封面主题。

验证：TypeScript 能独立解析曲目数据，资源路径保持站内绝对路径。

## 2. 全局播放状态

- 新建 `src/music/MusicProvider.tsx`。
- 只创建一个 `<audio>`，统一处理播放、暂停、拖动、音量、循环、自动续播、加载和缓冲事件。
- 在 Provider 中加载和解析 LRC，暴露当前歌词索引。
- 在 `src/main.tsx` 根部挂载 Provider，保证页面切换不重置音乐。

验证：首页与 `#music` 读取同一曲目、进度和播放状态。

## 3. WebGL 音频地形

- 新建 `src/music/AudioTerrain.tsx` 和独立样式。
- 使用 Three.js 场景、透视相机、环境光、定向光和单个 `InstancedMesh`。
- 将方块实例排成向远方延伸的地形，使用频谱数据驱动高度、亮度和轻微色相变化。
- 暂停时平滑回落，页面隐藏时停止动画，卸载时释放几何体、材质、渲染器和动画帧。
- WebGL 初始化失败时渲染 Canvas 2D 频谱降级视图。

验证：播放时地形响应，暂停时保留场景；切歌不重复创建音频源或 WebGL 场景。

## 4. 音乐舞台 UI

- 重写 `src/components/MusicPage.tsx`。
- 桌面端实现左侧原创封套与黑胶、纵向歌名/歌手、右侧歌词窗口和底部控制。
- 移动端实现全屏地形、中央歌词、底部两行控制。
- 新建 `RecordSleeve`、`SyncedLyrics`、`TransportControls` 小组件，避免主页面继续膨胀。
- 删除旧光球、同心圆和频谱边框结构，不保留兼容层。

验证：1440×900 与 390×844 截图符合书面规格，播放与暂停视觉状态同步。

## 5. 歌单与全站 Dock

- 新建 `PlaylistOverlay`，桌面左侧覆盖、移动端全屏覆盖。
- 选中歌曲后关闭歌单并立即播放，显示当前曲目和播放状态。
- 新建 `GlobalMusicDock`，在非音乐页显示小型音乐入口；点击可展开基本控制和进入音乐页。
- Dock 与音乐页都使用 `MusicProvider`，不创建第二个音频元素。

验证：从首页播放后进入音乐页不重置，返回首页继续播放。

## 6. 性能、可访问性与扩展兼容

- 桌面和移动使用不同实例数量及像素比上限。
- 歌词只渲染当前行附近窗口，并设置 `translate="no"` 与 `notranslate`。
- 支持 `prefers-reduced-motion`，限制高成本滤镜和阴影。
- 所有图形按钮补齐 `aria-label`，歌单使用 `listbox/option`。

验证：控制台无业务错误；沉浸式翻译不再遍历整份歌词；键盘可操作进度和音量。

## 7. 构建、测试与发布

- 运行 `npm run build`。
- Playwright 验证桌面和移动端播放、暂停、拖动、切歌、歌词、歌单、Dock 状态连续及截图。
- 源码提交后构建 `dist`，更新 GitHub Pages 静态仓库并推送 `main`。
- 轮询线上资源哈希，再对线上 `#music` 做一次播放和移动端截图验证。
